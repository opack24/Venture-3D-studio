# Venture 3D Studio

**Mission 2: Concept Image to Interactive 3D Studio**

[Launch the studio](https://opack24.github.io/Venture-3D-studio/) · [Mission 2 files](https://github.com/opack24/Venture-3D-studio/tree/main/Mission_2_3D_Studio)

Mission 2 is a browser-based 3D product studio seeded with an editable procedural interpretation of the supplied futuristic laundry folding station concept image. It provides model editing, reusable geometry templates, reference image and texture inputs, browser save/restore, JSON backup, GLB export, and a validated ZIP handoff for Mission 3.

The complete app and student guide live in [`Mission_2_3D_Studio/`](Mission_2_3D_Studio/). The app loads Three.js and JSZip from public CDNs and needs an internet connection. The starter geometry is a procedural interpretation of the image, not a scan or automatic image-to-3D reconstruction.
